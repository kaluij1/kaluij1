# Hi, I'm Jay Kaluiji

I studied physics at St. Olaf College with a concentration in engineering. I like working where simulation, data, and hardware meet: taking a problem from the equations to something that runs, then measuring how well it actually works.

I'm open to roles in mechanical engineering, simulation, and ML engineering.

## Projects

**[Jet Classification in Higgs Boson Decays](https://github.com/kaluij1/Jet-Classification-in-Higgs-Boson-Decays-at-the-LHC)**
Separating H → bb̄ jets from QCD background in 225,868 CMS events. Leakage controlled train, validation, and test splits, a physics cut baseline, tests, and CI. Random forest reaches 0.906 test AUC.

**[KSDD2 Defect Inspector](https://github.com/kaluij1/ksdd2-defect-inspector)**
Surface defect detection on the KolektorSDD2 dataset with a MobileNetV3 baseline, error analysis with Grad-CAM, a FastAPI service, Docker, and CI.

**[Nonlinear Pendulum Surrogate](https://github.com/kaluij1/non-linear-dynamics)**
Building a neural network surrogate for a damped nonlinear pendulum. The ground truth simulator and dataset pipeline are done; the model is in progress.

**[BOM Sourcing Agent](https://github.com/kaluij1/bom-sourcing-agent)**
Compares price, lead time, and stock for a parts list across supplier sites with no public API, using cloud browsers and an LLM for extraction.
